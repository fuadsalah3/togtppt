Security — Who Can Access What

Customer

Sees only their own data • Tracks own applications • Cannot see other users

Worker

Manages assigned users • Creates users / groups / packages • Cannot change roles

Guide / Imam

Sees assigned groups only • Tracks members in their group • Cannot modify user data

Admin (Manager)

Full control over all users • Can terminate accounts • Can assign / remove roles • Sees all reports

Tech Person

System health & maintenance • Can enable maintenance mode • Cannot see customer data • Cannot delete files
